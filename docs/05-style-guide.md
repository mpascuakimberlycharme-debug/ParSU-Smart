
ParSU-SMART Style Guide

1. COLOR PALETTE

Color          | Hex Code     | Usage

Navy Purple    | #1D1C5A      | Sidebar, buttons, and headings

Light Lavender | #E7E7FD      | Header and highlighted cards

White          | #FFFFFF      | Main background and content cards

Light Purple   | #DADAFB      | Borders and input fields

Dark Text      | #171747      | Main text and labels

Green          | #C9F2DF      | Approved and active status

Yellow         | #FFF0A8      | Pending status

Blue           | #D8E5FF      | Under Review status

2. TYPOGRAPHY

Font: Arial or similar sans-serif font
Headings: Bold
Body Text: Regular
Buttons and Labels: Bold

3. NAVIGATION DESIGN

- Dark navy purple sidebar
- ParSU-SMART logo at the top
- Dashboard
- Students
- Scholarships
- Applications
- Requirements
- Documents
- Staff
- Highlighted background for the selected menu

4. BUTTONS AND COMPONENTS

Primary Buttons: Navy purple background with white text
Secondary Buttons: White background with navy purple borders
Cards: White background with rounded corners
Forms: White fields with light purple borders
Tables: Lavender headers with organized rows
Status Labels: Rounded colored badges

5. LAYOUT AND RESPONSIVENESS

- Clean and organized dashboard
- Consistent spacing and alignment
- Rounded cards and input fields
- Sidebar navigation for desktop
- Responsive layout for mobile devices

6. DESIGN PRINCIPLES

- Simple and user-friendly
- Consistent colors and typography
- Easy navigation
- Readable information
- Organized layout
